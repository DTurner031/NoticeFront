# Índice de documentación frontend

Este directorio reúne la documentación técnica del frontend de Noti ICE.

## Documentos principales

| Documento | Contenido |
|---|---|
| `frontend-arquitectura.md` | Estructura del proyecto, capas, carpetas y flujo de datos actual. |
| `roles-y-permisos.md` | Roles del sistema, rutas permitidas y permisos esperados. |
| `flujos-frontend.md` | Flujos principales de uso: admin, docente, alumno y visitante. |
| `flujo-academico.md` | Lógica académica: planes, materias, grupos, asignaciones y suscripciones. |
| `checklist-pruebas-frontend.md` | Lista de pruebas manuales antes de integrar backend. |
| `frontend-api-ready.md` | Preparación para conectar el frontend con API REST. |
| `frontend-error-handling.md` | Páginas de error, estados de carga y manejo de errores. |
| `identidad-grafica-ipn.md` | Criterios visuales aplicados a partir del manual de identidad gráfica IPN. |

## Objetivo

Dejar claro cómo está organizado el frontend antes de iniciar el backend, para que la API de ASP.NET Core + MySQL se diseñe alineada con las pantallas y flujos ya implementados.
